## 环境与能力边界

- 原始发布验证使用 Linux、Node.js 25.9.0；最低声明为 22.19。2026-09-23 补测了 alpha.1 在 22.19.0 的安装、命令入口和工作台，以及当前源码的构建和指定测试，均通过。此补测没有调用真实模型。
- 完整源码开发建议使用已验证的 Node.js 25.9.0：源码包含一个要求 Node.js 23.6 以上的上游 gondolin 示例，在 22.19 安装会有告警；它不属于 alpha.1 工作台安装入口。
- 历史真实后端检查使用 Codex CLI 0.153.4 和 gpt-5.6-luna。协议与模型可用性可能变化；其他版本和系统没有兼容性承诺。
- 工作台使用 Codex 后端。Pi 后端通过命令行提供，需按 Pi 配置提供方；详见[开发参考](development/research-kernel.md)。
- 目前面向单用户本机研究，不提供公网多人服务、完整环境自动复现或服务重启自动接管保证。
- 决策独立审核、长期实验管理等后续研发不属于 alpha.1 的能力承诺。
- 真实固定协议案例尚未通过最终全流程验收。研究结果需要人工复核；任务结束不代表假设成立或论文可发表。

## 故障报告

请提供版本、操作系统、Node.js 与 Codex CLI 版本、脱敏错误和最短复现步骤。不要整份上传研究目录、登录信息或私人数据。使用[问题入口](https://github.com/Runder-sun/Astra/issues)；敏感安全问题按[安全说明](../SECURITY.md)处理。

项目目前没有长期支持版本或响应时间承诺。历史依赖审计只代表查询时点，不能作为当前安全保证。
