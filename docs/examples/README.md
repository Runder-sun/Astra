## 可以自己尝试的小问题

> 固定随机种子，比较均值和中位数在小型污染正态样本上的误差。只使用 Python 标准库，记录样本设置、重复次数、代码、原始数据、运行命令和失败记录。不声称方法创新。

首次选择 24 个任务，不交付论文。它是入门问题，**不是附带已验收结果的基准测试**，也不保证能在该预算内完成。

建议检查的材料：

| 材料 | 你需要检查什么 |
| --- | --- |
| 研究计划 | 分布、污染比例、样本量、随机种子和比较指标是否固定 |
| Python 源码与运行命令 | 能否独立运行，有没有偷换实验设置 |
| 原始结果与汇总 | 汇总值是否能从原始数据复算 |
| 结论与审阅 | 结论是否限定在测试条件内，负面结果和未决问题是否保留 |

## 已有真实案例：最终交付尚未通过

原始 alpha.1 技术记录报告了一次固定协议案例：两次 Python 运行各产生 300 行重复实验记录和 9 项误差汇总，并报告了独立复算及阶段审阅。但随后发现 PDF 截断、稿件状态过时和可编辑源码交付缺口，不能把它展示为全流程成功。

这段描述来自[已发布版本的历史记录](https://github.com/Runder-sun/Astra/blob/v0.1.0-alpha.1/packages/astra/README.md)，不是本次重新复算。当前此页面没有附上可公开下载的完整原始实验包，因此不将这些数值作为可独立验证的产品效果证明。

后续公开完整案例时，需同时提供固定问题与协议、软件版本、代码与原始数据、运行环境和命令、实际耗时与额度口径、审阅及失败记录、最终结论与缺失项。未满足时保留“未完成”状态。
