## 完整系统仍未关闭的差距

- Pi 主代理已能按本 job 的对象编号分页展开完整结构化证据、审核、问题和路线记录；不接受任意文件路径。主代理现可通过声明的 fileRef 分页读取冻结 UTF-8 文件，并核验哈希；原文件被覆盖不影响读取，未声明路径和损坏快照被拒绝。二进制 PDF、图片仍需文本提取或页面预览。整体审阅的三个文件和五条主张限制已从提示、技能、工具门控与提交格式移除，保留任务总预算；预算不足须报告未核验项。该能力不证明模型实际完成所有检查。
- 开放审核问题下，已加入修当前成果、回退上游或请求用户的策略选择；禁止直接推进或完成。修复输入重新绑定有效上游，旧失败成果仅作为显式历史对照，原问题保留到重新审核和验收。回归覆盖上游替换、返回原阶段、问题关闭及重开恢复；普通任务仍拒绝失效输入。
- 候选比较、采纳理由、路线决策的独立审核覆盖。
- 整体研究方案修订、父子目标、里程碑影响说明；完整 Git 工作树、合并与环境复现。
- 可操作的问题与假设状态、关键输入消费映射、跨研究知识索引。
- 长期实验运行身份、检查点、接管及取消；针对具体研究对象的人机交互。
- 从计划缺口、实现错误、版本替换、中断和用户转向到最终交付的完整真实模型验收。

## 验证范围

前几轮使用指定回归及模拟后端，不调用真实模型，不恢复用户现有研究，且当时未提交或发布代码。原有选定测试先通过；新增回归分别复现主张误判、快照恢复失败、可变下载、暂停锁冲突、审核预算拒绝及无回执来源，再验证修复。所有测试数量仅用于说明软件行为覆盖，不代表研究内容或整个系统已验收。

前轮 15 个核心测试文件共 120 项通过，包含串行与并行任务的暂停请求处理。另一个包含 Codex 模拟后端的五文件测试组共 75 项通过，与核心组存在重叠，不累加为独立测试数；来源工具测试亦通过。

后续修复先复现 PDF 交付校验缺失、第四份审阅材料被拒、输出条目截断和主代理读取入口缺失，再验证修复。六个指定文件共 64 项通过（worker-submission、pi-skill-loading、extension-task-budget、research-control、task-workspace-flow、repair-acceptance）。`npm run check` 通过，包括格式、依赖约束、类型、运行边界与浏览器构建冒烟检查。没有进行真实模型全研究验收。
