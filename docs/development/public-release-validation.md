## 发现并处理的问题

1. 原始公开树的边界清单要求 8 个不存在的 Rust 文件，导致 npm run check 失败。当前检查改为阻止旧运行时回到产品树，无须依赖历史代码。
2. 源码导出遇到尚未从索引移除的已删除文件会失败；旧白名单也漏掉新增文档与英文入口。回归覆盖删除文件、旧归档排除、用户文档及 Astra 工作流。
3. 原打包验证只复制 dist 和 web，缺少生产依赖，无法启动当前工作台。现按包声明在隔离目录安装生产依赖，再验证资源与执行器解析。
4. 首次源码测试没有构建工作区依赖，research 测试无法解析包入口；开发指南与持续检查均先离线构建再运行测试。

## 保留的限制

- 本轮没有真实模型调用，没有重新复算科学案例或完成论文最终验收。示例页不提供虚构成功结果。
- 清洁源码在 Node.js 22.19.0 安装时，上游 gondolin 示例声明需要 Node.js 23.6 以上，会产生环境告警；Astra 指定构建和检查仍通过。完整源码开发建议使用本轮验证过的 25.9.0，不能据此声称该上游示例支持 22.19。
- 源码依赖安装仍报告 4 项既有审计告警和上游弃用提示。本次未进行无关依赖升级；原始发布包独立安装的本次审计为零已知漏洞，仅代表查询时点。
- 新增 GitHub 工作流已在本机验证其核心命令；尚未在远端运行。页面、文档与归档删除需提交并合入 main 后才会反映在线上。
- 本地打出的修改版包只用于验证，版本号尚未递增，不能拿它覆盖原始 alpha.1 附件。发布新版本前另行确定版本并完成相应验收。
