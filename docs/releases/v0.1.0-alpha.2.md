# Astra v0.1.0-alpha.2

2026-10-04，面向单用户本机使用的实验版。安装包沿用内部 Pi 包名，独立通过本仓库 GitHub Release 分发；不发布上游 Pi 包，也不覆盖 alpha.1 标签或附件。

## 修改范围

- 任务和阶段计划绑定完整要求，修订沿最新有效成果推进；保留未关闭问题与原始失败记录。
- 增量成果继承精确冻结文件，审核、后续输入和下载使用同一版本，路径冲突明确拒绝。
- 执行批次按剩余轮数缩减；容量失败退款、费用门和历史用户确认继续生效。
- 持久交付先恢复再重试，保留审核、采纳、路由、暂停及用户指导的身份和状态。
- 中文及表情在请求、子进程输出和有限日志窗口中保持正确；各管道独立解码。
- 会话审计核对成功清单、审核成果目标、主会话调用历史和真实清理归档，整个审计只读。
- 源码导出及安装包追踪捕获的文件、校验值和提交来源；旧 Rust 不进入当前产品树。
- 中英文 README、安装指南和官网统一指向本版本，并补充研究流程和升级步骤。

## 验证记录

本次在 Linux 检查 Node.js 22.19.0 和 25.9.0。验证记录区分本仓库源码与独立安装包：

- 工作区离线构建、完整 `npm run check` 通过；模型目录校验与源码导出通过。导出的源码在仓库外使用 `npm ci --ignore-scripts` 干净安装，Node.js 22.19.0 下离线构建通过。
- Node.js 22.19.0 下在仓库外安装实际 tgz，命令入口通过；工作台页面资源、默认执行器解析及交付通知通过。工作台检查替换了模型调用部分，没有调用真实模型。
- 源码导出发现测试合成私钥标记触发隐私检查，已先复现、独立审核后修复。仅调整测试标记构造，产品扫描规则未变；23项源码导出测试通过，包括真实测试文件自身导出与私密材料拒绝。
- 本次发布相关6个脚本文件68项测试、仓库外源码的工作台与研究回归26项测试通过；导出源码的完整检查在 Node.js 22.19.0 下通过。
- 附件提供来源清单和 SHA256SUMS；最终打包、源码包安装构建及公开附件校验的命令结果随 `RELEASE_VALIDATION.json` 提供。

内核最后一轮修复经独立审核，50条标准通过；20个具名框架测试文件532项、6个具名发布脚本文件125项通过，共657项离线测试。完整类型、格式、依赖锁、运行边界和浏览器编译检查通过。终审补发现的 reviewer 目标身份遗漏已追加8项正式反例并关闭；初始候选的失败记录保留。

这些是软件及离线模拟验证，不是自主科研有效性或模型账号兼容性证明。本次不新增真实模型实验；历史 Codex CLI 0.153.4 / gpt-5.6-luna 记录不能视为当前 CLI 或模型的兼容承诺。

安装包仅包含 Astra 编译产物，运行依赖固定为公开的 Pi 0.84.1；源码附件另包含本仓库对 Pi 工作区组件的修改。657项测试针对仓库工作区，不能据此声称独立安装包已包含所有工作区组件修改。

2026-10-04 独立安装的生产依赖审计报告9项问题（8高、1中等，包含依赖链归因），主要涉及 undici、括号匹配和文件匹配依赖；本版未关闭这些问题，不是安全审计通过的版本。完整源码安装报告13项问题（10高、3中等）。原始审计结果作为附件保留，不使用自动强制升级改写已验证的依赖组合。

## 升级与限制

先暂停并确认旧进程停止，备份包含隐藏 `.astra` 的完整研究目录，再在新目录安装。旧版与新版不能并发写同一作业。调度锁已改用目录锁协议，未知旧锁所有者会明确报错，不会自动删除。历史预算门保留原有要求，升级不会自动降低额度或恢复任务。

平台验证限 Linux。关闭网页不会停止研究，服务重启后没有自动接管保证。原文、复现材料及论文页面仍须人工核验；最终真实研究案例尚未通过全流程验收，不保证收敛、创新性或发表质量。
