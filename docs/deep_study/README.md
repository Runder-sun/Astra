Method:

1. Read the design docs and key source files.
2. Extract concrete data models, storage contracts, hooks, and retrieval paths.
3. Separate directly reusable implementation patterns from ideas that should only
   inspire a new design.
4. Record findings immediately in the layer document instead of deferring to a
   final summary.
