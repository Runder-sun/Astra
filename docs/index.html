独立会话依据冻结标准审阅产物。未通过的项目保留为修复事项；修复后重新核验，不能用一句“已完成”代替证据。

03

保留过程与版本

记录任务、结果、决定和文件快照。上游成果变更会使相关下游结果失效，让旧结论不会悄悄成为新研究的依据。

YOUR NEXT QUESTION

从一个小问题开始。

建议先做一次有明确边界的小预算研究。通过本机工作台观察任务、检查证据，并在需要时调整方向。

源码运行需要 Node.js 22.19 或更高版本。Codex 后端需要已安装并登录的官方 Codex CLI；论文 PDF 预检需要 Poppler 的 pdfinfo。

SOURCE QUICKSTART
git clone https://github.com/Runder-sun/Astra.git
cd Astra
npm ci --ignore-scripts
npm run build:offline
export ASTRA_CODEX_MODEL=gpt-5.6-luna
node packages/astra/src/workbench.ts --root ./research --port 4319

启动后，在本机浏览器打开 http://127.0.0.1:4319。

PROJECT STATUS

开放实验，也开放边界。

Astra 目前是实验版。软件回归通过不代表研究结论正确，也不代表已经具备完整的自主科研能力。

决策的独立审核、长期实验接管、完整环境复现，以及真实模型全研究验收仍在完善。GitHub 源码持续更新；发行附件有各自的版本与验证范围。
