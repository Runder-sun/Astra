# 来源、历史与迁移

Astra 基于 Pi 0.84.1，当前源码保留运行所需的多包结构。Pi 负责模型调用、工具循环和会话等通用能力；Astra 负责研究状态、任务、审阅与成果采纳。

上游代码的 MIT 许可证和版权声明保留不变。Astra 的贡献、安全与发布规则独立于上游维护者。

## 旧 Rust 运行时

旧 Rust 文件已从当前源码树移除。公开主分支迁出前的 Rust 内容与现有 **v0.1.0-alpha.1** 标签一致，可在[固定历史入口](https://github.com/Runder-sun/Astra/tree/v0.1.0-alpha.1/legacy/rust)查阅；已有标签和发布附件不修改。

该标签保留的是当时公开的文件。迁出前的边界检查曾报告 8 个清单中的 Rust 文件不在公开树中，因此这里不宣称旧归档可完整构建。原始开发目录不在本次整理范围内，也没有被删除。

当前产品不需要检出或编译旧代码。需要研究历史行为时，在独立目录查阅该标签；不要将归档恢复到 main。历史设计记录中的旧路径是当时的说明，不是当前安装步骤。

## .pmcli 数据

当前 Node 实现保留只读迁移报告：`astra research migrate` 检查 `.pmcli` 并生成清单，不会把旧结果自动采纳为新研究事实。新研究状态使用 `.astra`。

## 原始源码清单

[alpha.1 源码清单](alpha.1-source-manifest.json)保留首版导出文件的校验值与来源基线，仅用于历史追踪，不描述当前 main。新源码附件在导出时生成自己的 `SOURCE_MANIFEST.json`。
