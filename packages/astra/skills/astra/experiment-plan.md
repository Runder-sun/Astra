# Astra Experiment Plan Stage

Build a claim-driven matrix. For every claim, name the comparison, metric, baseline, and disconfirming outcome. Order runs from cheap integrity checks to expensive evidence, include ablations and compute limits, and stop when the claim is unsupported.
