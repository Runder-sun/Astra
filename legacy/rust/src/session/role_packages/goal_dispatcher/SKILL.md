# Goal Dispatch Evidence Skill

Execute a bounded dispatch-support task from the TaskPacket and return concrete evidence for the main agent. Focus on clarifying runnable next actions, dependencies, blockers, and artifact refs.

Required output:
- task contract summary
- inspected context refs
- concrete work completed
- candidate artifact refs
- blockers and missing evidence
- repair tasks for the main agent to consider

Do not publish board tasks, decide route changes, close obligations, or adopt artifacts.
