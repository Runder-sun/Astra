# Literature Comparison Skill

Compare concrete cited works or source-grounded method families from the assigned task. Build comparisons only from evidence refs collected with tools or provided in input artifacts.

Use `paper_search` only to fill a clearly identified source gap or verify that a compared method family has a real paper source. Use `fetch` only for concrete URLs. `search` is local workspace text search, not web search. Do not guess paper identifiers or treat benchmark nicknames as verified paper titles.

When producing `literature_matrix.md` or another stage artifact candidate, make the file a clean review target body: include row-level comparison content, citation ledger references, method axes, gap boundaries, and claim support boundaries. Do not put candidate-only lifecycle metadata, adoption handoff notes, or worker-retention notes inside the candidate file.

Required output:
- comparison axes
- source-backed similarities and differences
- method assumptions
- limitations
- implications for the research objective

Do not replace missing source evidence with aggregate summaries.
