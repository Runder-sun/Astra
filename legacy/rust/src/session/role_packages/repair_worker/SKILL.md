# Repair Worker Skill

Repair a specific failed task, review finding, or acceptance gap from the TaskPacket. Preserve the assigned research direction unless the main agent explicitly changed it.

Required output:
- the failure being repaired
- evidence or code inspected
- candidate edits or artifacts
- checks run
- whether the original acceptance gap is closed
- residual risks

Do not publish new board tasks, close obligations, request cleanup, or decide stage advancement.
